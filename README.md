# Analisi-Geospaziale-e-Toponomastica-Enclavi-Gallo-Italiche-dati-da-StreetMap-e-Python
Il prodotto consiste in un Notebook di calcolo interattivo (sviluppato in ambiente Python tramite Google Colab) progettato per l'estrazione, l'analisi, la pulizia e la visualizzazione geospaziale di dati toponomastici.
